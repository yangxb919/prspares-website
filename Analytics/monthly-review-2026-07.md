### 三点必须记下的订正

1. **榜单文 id202 状态与 07-30 changelog 记录冲突**。07-30 在 GSC 界面读到"网址已收录到 Google"，今日 API 显示"已发现－尚未编入索引"且 **lastCrawl 为空**。一个从未被抓取的页面不可能被收录，因此判定 **07-30 的界面读数是误读**（很可能读到了实时测试结果而非索引状态）。以 API 为准：榜单文至今没被 Google 抓过。

2. **id139 的重抓不能归因给 sitemap 修复**。lastCrawl 07-30 10:41 UTC = 北京 18:41，而 lastmod 修复的部署时间是北京 **18:47**——重抓比修复上线早 6 分钟。**lastmod 修复至今约 21 小时，尚无任何一页在其后被重抓，效果为零证据状态。**

3. **手动"请求编入索引"在本站不稳定**：grade-guide 提交当天抓取+收录；hub156 与榜单文提交后 24-72 小时零反应。不能把它当成收录问题的通用解法。

→ **"该站抓取瓶颈不是内链"这个 07-30 的结论需要修正为：不是内链数量，是内链来源的权重。** grade-guide（57 篇内链）和 hub156（22 篇内链）都是被低流量页包围，GX 页只有 1 篇内链却被抓——差异在于抓取调度看的是发现路径的质量。
