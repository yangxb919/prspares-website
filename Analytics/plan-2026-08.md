# 8 月执行计划

## 零、7 月留下的三个硬事实（决定本月排序）

1. **收录闸没通过**：7 月造的 B2B 新页里，hub156 与榜单文至今**从未被 Google 抓取**，JK 抓了不收。手动请求编入索引在本站时灵时不灵。
2. **内链权重来源不对**：hub156 的 22 篇内链、grade-guide 的 57 篇内链，**没有一篇来自站内高流量页**；全站最大入口 id188（98 点击）连一条询盘表单链接都没有。
3. **B2B 自然搜索词池全月只有 278 次曝光 / 1 次点击**（全站 43,905 曝光的 0.63%），且位次多在 13-43。**靠自然搜索做 B2B，在这个站的量级上短期内不成立。** 同期 ChatGPT 带来 139 次 engaged 会话，07-31 的 5 封新 RFQ 5/5 归因 ChatGPT。

→ **本月主线换成：① 先让已造好的页被抓；② 顺着唯一有量的消费者症状池做转化；③ B2B 的主通道认定为 GEO + Ads + 社区，不再指望自然搜索短期起量。**

**A2. id188 漏斗补齐**（顺带解决第二节的转化缺口）：全站最大入口目前 0 条询盘表单链接 → 补 询盘表单 + WhatsApp 深链 + grade-guide 三件套。

**验收（08-07 复查点）**：跑 URL Inspection，看 hub156 / 榜单文 lastCrawl 是否出现、JK 是否转收录、16 篇 MOQ 修正文与 id139/id164 是否有 lastmod 触发的自然重抓。

**🔴 熔断**：若 08-07 三个页面仍全部未抓 → 判定"内链权重 + IndexNow"路线也无效，停止在收录上继续投入，改为承认该站抓取预算受限，把 B2B 内容重心整体移到 GEO 落点（llms.txt / 结构化事实 / 社区原生答案），不再为 Google 建页。

## 三、主线 B（P1，第 1-3 周）：消费者症状簇 —— 唯一有量的池子

7 月增长的 76% 来自这里，而它的漏斗基本是空的。

**B1. Phase 3.4 症状文补漏斗闭环**（已挂半个月，现在有数据支撑）：对 7 月点击 top 8 的消费者页统一补三件套（询盘表单 / WA 深链 / grade-guide），逐页做语境化 CTA，不套模板句。

**B2. CTR 改造，四个具体单点**（都是已排前 10 但点击接近 0 的词）：

| 词 | 曝光 | 点击 | 位次 | 承接页 |
|---|---|---|---|---|
| iphone boot loop repair cost | 175 | 1 | 7.3 | id188 |
| iphone 11 screen replacement | 117 | 0 | 9.7 | id126 |
| s23 ultra screen replacement cost | 98 | 0 | 8.7 | id128 |
| s23 screen replacement cost | 103 | 2 | 5.5 | id128 |

这四个词合计 493 曝光 / 3 点击。title 与 description 里补进「cost / 价格区间」这个查询里明写的词——07 月 best-value 页 retitle 已验证该手法有效（CTR 0.66%→2.41%）。

**B3. 新写 2 篇同类症状文**，选题从已验证的查询池延伸（不新开赛道）。写前按惯例 grep sitemap + 查已有支柱文防自我蚕食。

**注意（不做的事）**：`iphone screen repair near me` / `phone screen repair near me` / `iphone screen repair` 三词合计 376 曝光、位次 2.2-2.8、**0 点击**——本地维修意图，我们结构上接不住。**不优化、不写文，只在算全站 CTR 时把它们当噪音扣掉。**
